# What already exists

One slide answer to "isn't this already a thing?" The honest answer is yes, in
parts. This page is a map of the neighbouring work, not a claim that nothing
similar exists. As far as we could find, the combination below is unusual; no
individual piece is new.

## Slide outline

| Area | What already exists | What Dry Run adds | Source (fill in) |
| :--- | :--- | :--- | :--- |
| Email and text drills | Security awareness products send simulated phishing email and SMS and score who clicks. | The drill is a live conversation with pressure, not a link to click. | |
| Voice drills | Simulated vishing exercises exist for staff, often recorded audio with multiple choice answers. | The reply is written freely, in the participant's own words, and the pressure reacts to it. | |
| Scammer simulation research | Researchers study scam scripts and run scripted role plays with participants. | The same shape, shipped as a short public practice anyone can run alone. | |

| Scam awareness campaigns | Government and newsroom campaigns explain the pattern in text and video. | The explanation is replaced by a rehearsal: the person has to answer, not just read. | |
| Family mediated safety | Families warn elders by phone and share screenshots of suspicious calls. | A report link shows one family member the exact words that were said, with consent. | |

## What is genuinely different here, stated carefully

1. **Deterministic engine, optional model.** Turn labels and every debrief
   sentence come from rules; the model writes dialogue only. That makes the
   drill replayable and auditable, which a prompt only product cannot be.
2. **Practice, not a score.** No numeric result is reported
   The debrief gives one habit and the participant's own
   quote.
3. **Privacy as a default.** No account, tokens only in headers, seven day
   retention, deletion from the debrief screen, and a share link the
   participant can invalidate.

## How to use it in a pitch

Say: "email and text drills exist, staff vishing exercises exist, scam
detection exists. What we have not found is a free, single scenario, engine
driven rehearsal that a person can finish in ninety seconds and hand to one
family member, with the debrief quoting their own words." Then show the drill.
