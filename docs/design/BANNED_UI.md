# Banned UI Elements

**Status: BINDING. These rules override `docs/design/figma-designer.md` and `docs/design/landing-page-design.md` in all cases.**

The following 18 elements are banned from all UI surfaces (app, landing page, any generated design):

1. **Purple gradients** — no purple gradient backgrounds, borders, or fills anywhere.
2. **Lucide icons** — do not use the Lucide icon set.
3. **Sparkle icons** — no sparkle/glitter/magic-wand icons anywhere.
4. **3 cards in a row** — never lay out exactly three cards side by side in a row.
5. **Bento grids** — no bento-style asymmetric grid layouts.
6. **Glass cards** — no glassmorphism, frosted glass, or backdrop-blur card effects.
7. **Glowing orbs** — no decorative glowing orb or blob elements.
8. **Colour stripe on cards** — no top/left/right accent stripe or border on one side of a card.
9. **Inter or Geist font** — do not use Inter or Geist typefaces.
10. **Emojis in headings** — no emoji characters in any heading element.
11. **Em dashes everywhere** — do not use em dashes (—) as a general punctuation habit; rewrite sentences instead.
12. **3 pricing tiers** — no three-column pricing comparison layout.
13. **Fake testimonials** — no invented testimonials, quotes, or user stories.
14. **Dot grid backgrounds** — no decorative dot-grid or dot-pattern backgrounds.
15. **Hover animations** — no hover-triggered animations or transitions on any element.
16. **A "Vite + React" tab** — no framework tab selector showing Vite, React, or similar.
17. **Default favicon** — the Flutter default favicon and any framework-default favicon must be replaced before shipping.
18. **Lorem ipsum live** — no placeholder Latin text in any shipped path.
