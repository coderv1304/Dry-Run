Privacy

Last updated 15 November 2026

What the drill keeps

The drill keeps your messages and the debrief so it can show them back to you. A session is deleted automatically after seven days.

What it never asks for

There is no account, no email address and no phone number. The drill never asks for an OTP, a card number, a PIN or an account detail, and it warns you if a message looks like one.

Who can read a session

Only someone holding the session link or the report link can read it. A report link stops working when it expires, and you can delete the session at any time.

What a family member sees

When you create a report link, that person sees the debrief and the transcript. Nothing else is shared.

What is not collected

There are no analytics, no advertising trackers and no third party scripts on this page or in the drill.

If something looks wrong

Delete the session from the debrief screen and stop using the page. The drill is optional at every step.

Dry Run

Dry Run is a practice drill. It is not protection from fraud and it does not certify safety.
